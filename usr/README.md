# Professional Resume App

A modern, responsive, and beautiful resume/portfolio application built with Flutter.

## Features
- **Responsive Design**: Looks great on Mobile, Tablet, Desktop, and Web.
- **Modern UI**: Clean typography using Google Fonts and a professional layout.
- **Interactive**: Clickable email and phone links using url_launcher.
- **Sections**: About Me, Experience, Education, and Skills.

## Tech Stack
- Flutter
- Google Fonts
- URL Launcher

## How to Run
1. Ensure Flutter is installed.
2. Run `flutter pub get` to fetch dependencies.
3. Run `flutter run` to start the app.
